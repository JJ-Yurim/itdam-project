# 외부 서비스 정보

프로젝트가 사용하는 외부 서비스의 가입·설정·활용 정보를 정리한다. 실제 키·비밀번호는
저장소에 없으며 Jenkins 자격증명과 서버 환경 파일에만 존재한다.

## 1. GMS (AI API 프록시) — LLM·임베딩

| 항목 | 내용 |
| --- | --- |
| 용도 | ① 문장 평가(Gemini) ② 공동 책 본문 생성(Gemini) ③ 문장 임베딩(OpenAI 호환) |
| 가입 | 서비스 제공자 포털에서 API 키 발급 |
| 키 주입 | Jenkins `gms-api-key` → ai-service `LLM_API_KEY`·`EMBEDDING_API_KEY` (동일 키) |
| 평가/책 생성 엔드포인트 | `https://llm-gateway.example.com/gmsapi/generativelanguage.googleapis.com/v1beta` (`generateContent`) |
| 임베딩 엔드포인트 | `https://llm-gateway.example.com/gmsapi/api.openai.com/v1/embeddings` |
| 사용 모델 | 평가 `gemini-3.5-flash` · 책 생성 `gemini-2.5-pro` · 임베딩 `text-embedding-3-small`(768차원) |
| 주의 | GMS 프록시가 긴 응답을 간헐적으로 절단한다 — ai-service가 잘린 envelope을 감지해 재시도한다. 임베딩 차원(768)은 DB `vector(768)` 컬럼 정의와 반드시 일치해야 하며, 바꾸려면 마이그레이션과 전체 재임베딩이 필요하다 |

## 2. 소셜 로그인 (OAuth2)

공통 사항:

- 콜백(redirect URI)은 프록시 뒤라 `{baseUrl}` 추론이 어긋나므로 명시한다. 배포 기준:
  `https://app.example.com/api/login/oauth2/code/{kakao|naver|google}`
- 로컬 개발 기준: `http://localhost:8080/api/login/oauth2/code/{provider}`
- 이메일 제공에 동의하지 않으면 가입이 진행되지 않는다(`social_email_not_provided`).
  계정 매칭은 `(provider, provider_id)`이고 소셜 계정은 비밀번호가 없다.

### 2.1 Kakao

| 항목 | 내용 |
| --- | --- |
| 가입 | [Kakao Developers](https://developers.kakao.com) → 애플리케이션 추가 |
| 설정 | 카카오 로그인 활성화, Redirect URI 등록(위 공통), 동의항목: `account_email`(필수 동의), `profile_nickname` |
| 키 | REST API 키 = client-id, 보안 탭의 Client Secret 발급 → Jenkins `develop-kakao-oauth` |

### 2.2 Naver

| 항목 | 내용 |
| --- | --- |
| 가입 | [Naver Developers](https://developers.naver.com) → 애플리케이션 등록 (네이버 로그인) |
| 설정 | 서비스 URL·Callback URL 등록, 제공 정보: 이메일 주소(필수), 별명 |
| 키 | Client ID / Client Secret → Jenkins `develop-naver-oauth` |

### 2.3 Google

| 항목 | 내용 |
| --- | --- |
| 가입 | [Google Cloud Console](https://console.cloud.google.com) → OAuth 동의 화면 구성 → 사용자 인증 정보에서 OAuth 클라이언트 ID(웹) 생성 |
| 설정 | 승인된 리디렉션 URI 등록(위 공통), 범위: `email`, `profile` (OIDC 대신 커스텀 UserService를 태우려고 `openid` 미포함) |
| 키 | 클라이언트 ID / 보안 비밀 → Jenkins `develop-google-oauth` |

## 3. Gmail SMTP — 이메일 인증 발송

| 항목 | 내용 |
| --- | --- |
| 용도 | 회원가입 이메일 인증 코드 발송 |
| 가입 | Google 계정에 2단계 인증 설정 후 **앱 비밀번호** 발급 (일반 비밀번호로는 SMTP 인증 불가) |
| 설정 | `smtp.gmail.com:587`, STARTTLS. `SMTP_USERNAME`(주소)·`SMTP_PASSWORD`(앱 비밀번호) → Jenkins `develop-smtp` |
| 폴백 | 미설정 환경(local·test)은 발송 대신 로그로 대체되고, 인증 상태 저장도 Redis 대신 인메모리를 쓴다 |
| 주의 | SMTP 장애가 배포 헬스체크를 물고 넘어지지 않도록 actuator mail 인디케이터는 꺼 두었다 |

## 4. 참고 — 외부 서비스가 아닌 것

- 이미지 저장은 S3 등 외부 스토리지가 아니라 **EC2 호스트 볼륨**(`/var/www/images`)이다.
- 표준국어대사전 기반 단어 시드는 외부 API 호출이 아니라 **정적 JSON ETL**
  (`docs/operations/word-seeding.md`)로 적재한다.
